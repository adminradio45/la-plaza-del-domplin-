# La Plaza del Domplin

Professional static restaurant website designed for GitHub Pages.

## Included
- Home
- Menu
- Specials
- Reservations
- Gallery
- About
- FAQ
- Contact
- Responsive mobile layout
- Custom red and white visual identity
- Local image assets
- Favicon
- 404 page

## Important
Menu items, prices, forms, business hours, location and contact details are placeholders/demo content until officially verified.

## GitHub Pages
Upload the contents of this ZIP to the root of the repository, then enable GitHub Pages from the `main` branch and `/(root)`.
